Screenshots — Pending Student Action
=====================================

No real screenshots are included in this folder or in User_Manual.pdf /
Project_Documentation.pdf. Per the documentation brief, screenshots must
never be fabricated — only genuinely captured images may be used.

Why they are missing: this documentation package was generated in an
environment with no browser automation tool available, so the running
application could not be driven and photographed.

     User_Manual.pdf):

       - Login Error State
       - Dashboard
       - Inventory List
       - Add Item Form
       - Item Detail
       - Stock In Dialog
       - Stock Out Dialog
       - Sales Tab
       - Low Stock View
       - Suppliers Tab
       - Reports Tab
       - Settings Tab
       - AI Chat Panel
       - AI Forecast Panel
       - Logout Confirmation
  3. Save each as a PNG or JPG in this folder using the same name as the
     placeholder (e.g. "Dashboard.png").
  4. Insert each image into the corresponding placeholder in
     User_Manual.pdf (and, if desired, Project_Documentation.pdf) before
     final submission.
