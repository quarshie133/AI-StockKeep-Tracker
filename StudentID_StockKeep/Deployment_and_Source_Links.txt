=========================================
Important caveat — data persistence:

The live deployment's database (SQLite) runs on a workaround (copying
the database file into Vercel's writable /tmp directory on each cold
start — see Technical_Debt_Plan.pdf, TD-08) that was needed to make
the live site functional at all. Without it, every data operation on
the live site returned a server error. This workaround makes the site
USABLE but /tmp is EPHEMERAL — data added during a demo/grading
session may not persist indefinitely and could reset on a Vercel cold
start. If this matters for grading, note this limitation rather than
assume it is a new bug; it is documented, known behaviour.
